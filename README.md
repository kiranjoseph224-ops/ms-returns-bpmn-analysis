# M&S Returns Process Analysis (BPMN)

## Overview
Analysed Marks & Spencer's customer returns and refunds process as part of a team of 4, for the CSC1016 module. The project produced a 23-page report mapping six core workflows using BPMN 2.0, identifying operational pain points, and proposing process improvements.

## My Role
**Project Co-ordinator & Editor**

- Co-ordinated the team of 4, managing workflow, deliverables and deadlines
- Integrated contributions from all team members into a single coherent report
- Edited and structured the final 23-page document for submission
- Contributed to the requirements gathering and written process descriptions

## Technologies & Tools Used
- BPMN 2.0 (bpmn.io)
- Microsoft Word
- Process Mapping
- Requirements Gathering

## Processes Documented
1. Return Initiation
2. Return Eligibility Validation
3. Item Receipt and Inspection
4. Refund Processing
5. Customer Communication and Notification
6. Complaint and Escalation Handling

## Key Findings
- 10+ operational pain points identified, including refund delays of 3–4 weeks, system outages halting processing, and inconsistent customer communication
- 5 high-level improvements proposed to reduce processing time and improve transparency
- 10 business rules documented (BR-01 to BR-10)
- Success criteria defined, including processing 95% of standard returns within 10 business days
